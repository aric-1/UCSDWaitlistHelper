UCSD Waitlist Estimator

Estimate waitlist movement using past sections

About

This tool uses historical class + section data to estimate how many spots the waitlist will move. It uses time since the second pass opened as a metric to compare your current situation to past sections.

  • Data source: UCSD Historical Enrollment Data
  • Project source: GitHub

This tool normalizes past sections to your input section capacity in order to calculate the average waitlist movement. All past sections are weighted equally regardless of their actual capacity. This tool does not account for factors like the desirability of certain section times.
