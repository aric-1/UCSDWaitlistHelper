**UCSD Waitlist Helper**

A web application to help UCSD students understand their chances of getting off course waitlists based on historical enrollment data.

**Features**

Input your course code, section capacity, waitlist position, and time that the quarter's second pass begins (when waitlists open)

Uses historical per-section enrollment data to estimate seat openings

**Data Source:**

[Historical enrollment data from past UCSD terms](https://github.com/UCSD-Historical-Enrollment-Data/)

Only Winter 2025 data for now. Planned updates to support Fall quarters, which run on a different schedule.
